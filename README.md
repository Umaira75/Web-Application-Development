# Web Application Development

This repository contains web development projects completed during my Software Engineering studies.

## Projects

### 1. Police Fine Management System

A web-based application developed to manage traffic fines and improve the fine management process.

**Technologies Used:**
- PHP
- HTML
- CSS
- JavaScript
- MySQL
- XAMPP

**Main Features:**
- Police officer and citizen login
- Digital fine issuance
- Fine record management
- Citizen fine history

### 2. Care Compass Hospital Management System

A web application developed to support hospital management activities.

**Technologies Used:**
- PHP
- HTML
- CSS
- JavaScript
- MySQL
- XAMPP

**Main Features:**
- Patient registration
- Doctor appointment booking
- Staff management
