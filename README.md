# Web Application Development

This repository contains web development projects completed during my Software Engineering studies.

## Projects

### 1. Police Fine Management System

A web-based application developed to manage traffic fines and improve the fine management process.

**Technologies Used:**
- PHP
- PhpMyAdmin
- HTML
- CSS
- JavaScript
- MySQL
- XAMPP

**Main Features:**
- Police officer and user login
- Functionalities to issue fines
- Pay fines online 
- Submit appeals
- View appeal
- fine details

**Technologies Used:**

- MySQL

**Main Features:**
